# 数据结构：红黑树与 B+ 树

## 红黑树如何限制高度
红黑树是带颜色约束的二叉搜索树。根节点和空叶子为黑色，红节点的孩子必须是黑色。从同一节点到其所有空叶子的路径含有相同数量的黑节点。最深路径不可能比最浅路径长一倍以上，因此有 n 个内部节点时，高度至多为 2 log₂(n+1)。精确查找沿有序键向左或向右下降，时间复杂度为 O(log n)。

## 旋转与重新着色
插入新键先按二叉搜索树次序定位，再将新节点标为红色，以保持已有路径的黑高。如果父节点也为红色，应结合叔节点颜色区分处理。叔节点为红色时可重着色并向上检查；叔节点为黑色时，结合单旋或双旋修复。旋转保持中序遍历的键顺序，重新着色与旋转共同恢复颜色约束，仅检查根的颜色不足以证明修复成功。

## B+ 树的页与扇出
数据库索引常将一个 B+ 树节点存储在一个页中。内部节点保存分隔键和子页指针，记录或记录定位信息位于叶页。一个页可容纳许多分隔键，因此在相同记录数量下通常比二叉树更矮。若扇出约为 100，三层内部节点理论上最多可指向约一百万个叶页；实际容量仍取决于页利用率与键宽。

## 点查、范围查与页分裂
点查沿内部分隔键定位一个叶页。范围查询先定位下界，再沿有序叶链向后扫描，直到超过上界。例如查找键 30 至 42，找到包含 30 的首个叶页后，可顺序扫描相邻叶页而无需为每个键重新从根出发。插入时叶页容量不足会导致页分裂，并将新的分隔信息插入父页；若父页也满，分裂可能向上传播。

## 比较与选型
两类树都维护有序键。红黑树适合内存中频繁更新的有序映射；B+ 树通过高扇出与叶链减少外存随机访问并支持连续区间扫描。选型练习：若需要磁盘上十亿条日志按时间范围读取，应估计页访问次数，而不能仅比较大 O 记号。若任务只是内存里反复插入、删除少量键，应把节点维护成本和缓存局部性纳入比较。
