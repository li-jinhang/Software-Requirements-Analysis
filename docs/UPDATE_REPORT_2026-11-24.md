# LangGraph 教学流程与原版工作台联调更新报告

本次更新将需求规格说明书 U0003、U0004 的费曼反向教学流程实现为真实 LangGraph 状态图，并接通仓库原有 React 双窗工作台。学生可以在原界面完成账号登录、资料上传、角色开场、讲解、右窗查证、角色切换及历史恢复，教学记录和记忆变化由服务端保存。

更新日期：2026 年 11 月 24 日。最初实现基线：`f2fa96a`；发布前整合远端 12 个提交至 `f0e0326`。本报告与实现代码、测试和验收说明一同归档。

交付目标：`main`。实现与报告最初推送至 `codex/langgraph-integration` 供审查，随后按项目负责人要求合入 `main`。推送前已同步远端，保留既有提交历史，不使用强制推送。

## 远端整合

保留远端统一模型设置、本机配置导入导出、ChatGPT 授权、双窗即时消息与流式预览、图谱切换、并发解析、拓扑复讲路径和脱敏数据导出。LangGraph 通过现有 `ModelConnection` 复用“环节覆盖 → 默认方案 → 环境默认值”的模型绑定。未配置模型时保留 409 配置引导，生产流程不返回规则模拟教学。百科和报告继续使用远端真实模型实现。

## LangGraph 实现

核心实现位于 `backend/app/agents/teaching/`，`feynman_agent.stream(db, turn)` 保留原入口签名，内部执行已编译的 `StateGraph`。

正常流程为：读取上下文 → 输入分流 → 原文检索 → 结构化评估 → 校验或一次纠错 → 计算记忆变化 → 流式追问 → 保存记忆结果。开场、卡壳、偏题和资料缺少知识点时走对应分支。

主要文件职责：

| 文件 | 职责 |
| --- | --- |
| `backend/app/agents/teaching/graph.py` | 状态图节点、条件分支、掌握度规则和记忆保存点 |
| `backend/app/agents/teaching/schemas.py` | 图状态、Pydantic 评估结构及范围约束 |
| `backend/app/agents/teaching/prompts.py` | 评估、角色追问和开场提示 |
| `backend/app/agents/teaching/model.py` | 复用统一模型连接、有限重试与真实流式文本；规则仅供测试夹具 |
| `backend/app/api/v1/sessions.py` | 会话鉴权、开场、角色切换、SSE、事务与历史恢复 |

评估中的学生证据必须来自本轮输入，课件证据必须逐字出现在召回片段中；评估节点 ID 必须与当前教学目标一致。畸形 JSON、非法分数或伪造证据经一次纠错仍无效时，保留追问并跳过数值更新。

数据库连接通过运行时上下文注入，不放入图状态。远程推理期间释放只读事务；回复结束后在短写事务中应用记忆变化。记忆更新使用保存点隔离，最终由 API 同时提交消息与记忆，提交成功后才通知前端掌握度变化和 done。

同一会话内的开场、教学、角色切换和生成报告按顺序处理。断线恢复读取历史时等待已接收轮次完成，避免用户因读取到旧历史而重复发送。当前仍按单 Uvicorn worker 部署。

## 原版前端接入

保留现有页面布局、配色、资料卡片、双窗、图谱和报告组件，未重写视觉样式。修复内容包括：

- 在线登录后从服务端加载资料、知识记忆、薄弱点、会话和报告；打开会话时恢复双窗历史。
- 在线开场调用后端接口，左右窗消息仅发送 content，角色切换通过独立 PATCH 提交。
- SSE 读取 delta、citations[]、updates[] 和 done.message_id，正确处理 UTF-8 分片、CRLF、提前结束和错误事件。
- 引用卡片显示实际召回原文；评估徽章与图谱使用服务端掌握度。
- 笔记同步、记忆档案导出、管理员 JSON／SQLite 下载使用正确的鉴权接口。
- 管理员四张审阅表按真实字段显示名称、状态和时间。
- 仅在本地缓存未发送草稿与未同步笔记；已保存的知识、消息、评分及引用从服务端恢复。
- 身份失效时提示重新登录；切换账号时输错密码不会使原账号令牌失效。

## 接口与兼容性

| 变化 | 兼容说明 |
| --- | --- |
| `POST /api/v1/sessions` | 增加可选 node_id，原有不传节点的请求继续可用 |
| `POST /api/v1/sessions/{id}/opening/stream` | 新增角色开场接口，同一会话重复调用不会重复插入 |
| `PATCH /api/v1/sessions/{id}/persona` | 实际角色变更时追加分隔消息 |
| Session 响应 | 新增可空 target_node_id |
| 助手消息 meta_json | 保存评估证据、连续次数、模式和实际图节点路径；不作为额外 SSE 数据泄露 |
| 已有 SQLite | 启动时兼容补充 target_node_id，保留既有数据 |
| 开发启动器 | 默认前端 5173、后端 18080，支持自定义端口和 --frontend-only |

后端新增依赖固定为 `langgraph==1.2.24`。前端沿用现有依赖锁文件，接口测试使用 Vite 已依赖的 esbuild，无新增测试框架。

## 启动与验收

安装依赖后，在仓库根目录执行：

```powershell
.\backend\.venv\Scripts\python.exe dev.py
```

工作台地址为 `http://127.0.0.1:5173/`，接口文档为 `http://127.0.0.1:18080/docs`。如后端已启动，可用 `dev.py --frontend-only` 仅启动前端。完整步骤见 [原版工作台验收说明](FRONTEND_LOCAL_ACCEPTANCE.md) 和 [LangGraph 验收说明](LANGGRAPH_ACCEPTANCE.md)。

先在“设置 → 模型配置”保存连接方案并分配教学模型，再通过账号表单登录服务端学生账号。

## 已知边界与后续验收

生产教学必须配置可用模型，支持工作台管理的 API 连接与 ChatGPT 授权，也支持 `backend/.env` 的环境默认值。确定性规则仅由测试夹具显式注入。尚未用真实供应商验收教学质量、实际首字延迟及并发容量，模型替身测试不能替代这些检查。

文档未规定固定加减分公式和高质量阈值。本实现采用“准确度与通俗度均至少 80、无已识别漏洞、回应当前深度追问”的评审细则；连续两轮后至少达到 80，未通过两轮的新节点最高 79。细节见 LangGraph 验收说明，后续可按教学量规调整。
