# 斜杠菜单、Skills 与 MCP 本地验收

功能先在下载解压的项目目录中实现并本地验收，随后整合远端 `75e9409` 的 AI 单窗讲解、复习与考核拆分、登录空间挂载和账号删除更新。启动后打开 http://127.0.0.1:5173/ ，通过账号入口选择服务端学习账号。

## 1. 输入 / 使用能力

在双窗输入框开头输入 `/`，出现灰白圆角菜单。继续输入名称、描述或命令筛选，↑ ↓ 移动，Enter 选择，Esc 关闭，Shift+Enter 换行。中文输入法确认候选时不发送。普通文字中间的斜杠不触发菜单；输入 `//` 可发送以斜杠开头的普通文字。

| 命令 | 行为 |
| --- | --- |
| /help、/tools | 查看命令及项目工具 |
| /role，或 /role examiner | 选择或切换听众，保留上下文 |
| /lookup 学习率 | 在右窗返回当前课件的检索原文，并记录查证 |
| /progress | 展示当前资料节点掌握度与未解决薄弱点 |
| /history | 展示近期教学对话，不递归嵌套工具输出 |
| /review | 打开独立的间隔复习页面，保留与费曼考核分开的流程 |
| /report | 确认结束后生成诊断报告，仍需至少两轮真正讲解 |
| /graph | 打开当前资料图谱 |
| /model | 打开模型配置，保留整行切换功能 |
| /skills | 打开技能管理 |
| /mcp | 打开 MCP 管理 |

技能和工具操作单独保存消息，带 `no_assessment` 元数据，不更新掌握度，也不充当报告所需的讲解轮次。成功的操作可刷新恢复，在消息中下载 Markdown 结果。工作台“能力运行记录”可查看最近执行状态。重复请求有记录 ID 防重；外部工具失败或断线时不假定目标系统已回滚，需要核对目标服务结果。

## 2. 安装自己的技能包

右上角“能力中心 → Skills”中导入 ZIP。包内必须只有一份 `SKILL.md`，允许外层目录；YAML 头至少含 name、description，正文为技能说明。可附带 references、templates 等文本资源。

1. 点击“下载示例技能”，导入刚下载的 `study-review.zip`。
2. 回到对话，输入 `/study`，选择 study-review。
3. 输入框出现“仅本次任务”标签，输入“结合当前课程整理复习提纲和三道自测题”并发送。
4. 检查技能流式输出、保存后的 Skill 版本徽章及“下载结果”。执行时需要可用的百科环节模型。
5. 刷新，检查结果恢复，原掌握度没有因技能任务直接改变。
6. 在能力中心停用技能，菜单显示不可用；启用后恢复。重复导入提示冲突，勾选“更新同名技能”可以更新。

每个账号只管理自己的技能。管理员可把自己安装的技能设为公共，其他账号可读取和调用，但不能修改或卸载公共技能。技能正文只在执行时加载，不在每轮教学中全部注入。导入包含路径穿越、符号链接、超量资源或多个 SKILL.md 的包会被拒绝。

当前支持说明、参考资料、模板类技能。含可执行脚本、allowed-tools 或 compatibility 环境声明的包会显示“需要适配”，不会自动执行脚本、安装系统软件，或借用桌面软件的工具权限。

## 3. 接入 MCP 服务

支持官方 MCP Python SDK 1.30.0 的 Streamable HTTP，配置 URL 和可选 Bearer 令牌。连接管理和调用从运行服务的本机工作台执行。第三方服务如需要 OAuth、stdio 或特殊登录流程，需要后续单独适配；当前不会把不支持的连接伪装为可用。

为本地验收附带了一个真正的 MCP 服务，提供归档笔记、列出/读取笔记、生成日历提醒文件四个工具：

```powershell
# 在项目根目录另开终端；如果已经运行则无须重复启动
.\backend\.venv\Scripts\python.exe backend/scripts/learning_mcp.py --port 18090
```

1. 能力中心 → MCP 服务 → 添加，名称填“学习档案”，地址填 `http://127.0.0.1:18090/mcp`，令牌留空。
2. 点击“连接 / 刷新工具”，应显示四个工具和参数说明。
3. 在对话输入 `/archive`，选择 archive_learning_note。
4. 标题和最近的助手输出会预填到表单，可修改后“确认执行”。结果返回记录编号和文件位置。
5. 输入 `/list_learning` 或 `/read_learning`，检查列表和刚归档的笔记。
6. 输入 `/create_review`，选择 create_review_reminder，核对标题和日期后确认。

示例服务将文件保存在 `backend/data/mcp-notes/`。提醒工具创建 `.ics` 文件，需要用户导入个人日历后才会生效，不代表已向第三方日历写入或启动了通知任务。实际第三方 MCP 服务可提供自己的日历或笔记工具，参数表单根据工具声明生成，并保留高级 JSON 编辑。

只有实际发现的工具进入菜单。服务停用或连接失败时工具会标为不可用。参数依据服务最新 schema 再次校验；调用前必须确认。令牌不会返回前端列表，不进入教学消息或业务数据库导出。更换服务地址时不能静默复用原令牌。

## 4. 数据与验证

技能、MCP 配置和运行记录保存在数据目录 `capabilities/private.sqlite3`，按服务端账号隔离；与既有学习业务 SQLite 分开。现有学习账号备份不包含新能力目录，迁移这些能力需要重新导入技能、配置连接。不会读取开发者个人的 Codex Skills 目录。

技能任务通过独立 LangGraph 分支运行，MCP 调用也进入独立工具分支；原教学图保持 SQL＋RAG、评分及纠偏流程。远程模型等待期间不持有业务写锁，消息提交成功才发送 done；断线后已接受任务继续完成。暂未增加任意脚本沙箱、多技能自动协作、MCP OAuth 及用户之间共享 MCP 凭据。

整合远端后的验证：后端完整回归 80 项通过；前端接口及命令解析 16 项通过；真实 MCP HTTP 的发现、笔记归档、ICS 生成、参数校验通过；浏览器隔离测试覆盖菜单搜索、键盘选择、技能标签、流式显示、MCP 参数表单、能力中心及桌面/390px 窄屏；TypeScript、生产构建、pip check 通过。浏览器测试使用拦截的验收数据，不修改个人模型或账号，不代表真实供应商的语义质量验收。

整合时保留了远端账号删除的二次确认和退休账号编号机制，并在业务删除成功后清理该账号的技能、MCP 凭据与运行记录。补齐备份文档的可空 library_id 字段，使新旧账号备份可以恢复。开发启动器会一并检查和补装 MCP、YAML 与 JSON Schema 依赖。
